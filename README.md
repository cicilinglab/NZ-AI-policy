# AI Policy Explorer

Interactive views of AI governance and regulation, with Aotearoa New Zealand highlighted.

**Website: [AI Policy Explorer](https://cicilinglab.github.io/NZ-AI-policy/)**

## Explore

- [AI Governance Timeline](https://cicilinglab.github.io/NZ-AI-policy/AI_Governance_Timeline_2019_2026_NZ_Interactive.html) — international policy milestones from 2019 to 2026, with search, filters, zoom, event details, and source references.
- [Regulation Landscape](https://cicilinglab.github.io/NZ-AI-policy/AI_Regulation_Landscape_2026_NZ_Interactive.html) — a 2026 comparison of Brazil, Canada, China, the European Union, the United States, and New Zealand across 25 policy criteria. Click a comparison cell to inspect its evidence and references.

## Local preview

Run this command from the repository directory:

```sh
python3 -m http.server 8765
```

Then open [http://localhost:8765/](http://localhost:8765/).

The site uses standalone HTML files and is published through GitHub Pages from the root of the `main` branch.
